# Задача 3.2 — Поиск повторяющихся абзацев по хешам (Nim)

## Условие

Программа принимает путь к текстовому файлу, делит его на абзацы (разделитель — 
пустая строка), нормализует каждый (обрезка пробелов, сведение пробельных символов 
к одному пробелу, приведение к нижнему регистру) и вычисляет хеш — самостоятельно 
реализованный FNV-1a (64 бита). Абзацы с одинаковым хешем группируются, и для 
каждой группы текст сравнивается напрямую, чтобы исключить коллизии. В консоль 
и в отдельный файл отчёта выводятся группы повторов: номера абзацев, число 
повторений и начало текста. При отсутствии исходного файла программа сообщает об ошибке.

## Что делает код

1. Проверяет наличие входного файла и читает его содержимое.
2. Разбивает текст на абзацы по пустым строкам (с корректной обработкой Unicode).
3. Нормализует каждый абзац с использованием модуля `unicode` (`toRunes`, `toLower`) 
   и вычисляет его 64-битный хеш FNV-1a (реализован вручную).
4. Группирует абзацы по хешу, а затем внутри групп выполняет прямое посимвольное 
   сравнение текста для исключения ложных срабатываний (коллизий).
5. Сортирует найденные группы по номеру первого абзаца и выводит результат в консоль 
   и в `report.txt`. Превью текста безопасно сокращается по символам (runes), 
   чтобы не разрезать многобайтовые символы UTF-8.
