# Задача 3.1 — Слияние нескольких CSV-файлов с общим заголовком (Perl)

## Условие

На вход подаётся список CSV-файлов с одинаковым заголовком. Разбор учитывает 
кавычки, запятые и переводы строк внутри полей. В итоговый файл записывается 
общий заголовок плюс служебный столбец `_source` с именем файла-источника, 
порядок записей сохраняется. Если заголовки файлов не совпадают, программа 
сообщает, какие именно столбцы отличаются, и завершается с ошибкой.

## Что делает код

1. Читает список файлов из `input.txt` и инициализирует парсер `Text::CSV` 
   в режиме `binary => 1` для корректной обработки переносов строк и кавычек.
2. Выполняет строгую построчную проверку заголовков всех файлов. При несовпадении 
   выводит детальный отчёт о различиях (номер столбца, ожидаемое и фактическое имя) 
   и завершает работу с ошибкой.
3. Создаёт `output.csv`, записывает объединённый заголовок со столбцом `_source`.
4. Последовательно считывает данные из каждого файла, добавляет имя файла-источника 
   к каждой строке и записывает результат, подсчитывая общее количество записей.
5. Корректно работает с кодировкой UTF-8 на всех этапах ввода-вывода.
