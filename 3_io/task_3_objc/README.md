# Задача 3.3 — Утилита «последние N строк» с чтением с конца файла (Objective-C)

## Условие

Программа принимает путь к файлу и число N. Она должна вывести последние N строк 
файла, не загружая его целиком в память. Для этого файл читается чанками с конца. 
Программа вычисляет и выводит точное байтовое смещение начала первой выведенной 
строки. Корректно обрабатываются граничные случаи: пустой файл, файл с меньшим 
числом строк, чем N, и наличие завершающего символа новой строки.

## Что делает код

1. Строго валидирует аргументы, используя `strtoull` и проверку `errno` для 
   безопасного преобразования N в целое число.
2. Открывает файл через `NSFileHandle` и определяет его общий размер.
3. Читает файл чанками по 4 КБ в обратном направлении, подсчитывая символы `\n`. 
   Специальный флаг игнорирует одиночный завершающий `\n`, чтобы не считать 
   пустую строку в конце файла.
4. Вычисляет точное байтовое смещение начала целевого фрагмента.
5. Потоково выводит найденный фрагмент в `stdout` через `fwrite`, читая его 
   чанками.
6. Использует вложенные `NSAutoreleasePool` внутри циклов для предотвращения 
   утечек памяти и поддержания константного потребления RAM при работе с 
   большими файлами в среде GNUstep.
