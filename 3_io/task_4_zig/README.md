# Задача 3.4 — Резервное копирование файлов с проверкой целостности (Zig)

## Условие

Программа получает путь к исходному файлу и создаёт его резервную копию 
в указанном каталоге. Копирование выполняется блоками, без загрузки всего 
файла в память. Для исходного и скопированного файлов вычисляется контрольная 
сумма на основе самостоятельно реализованного алгоритма CRC32. Результаты 
записываются в отдельный файл-манифест. Предусмотрен режим проверки резервной 
копии, в котором программа сравнивает контрольные суммы и сообщает о повреждении данных.

## Что делает код

1. Реализует алгоритм CRC32 (полином 0xEDB88320) в виде структуры с методами 
   для инкрементального обновления хеша.
2. Копирует файл чанками по 64 КБ с использованием `std.Io` потокового чтения/записи 
   (`readerStreaming`, `writerStreaming`), что гарантирует константное потребление памяти (O(1)).
3. После копирования независимо пересчитывает хеш резервной копии для первичной проверки.
4. Создаёт текстовый файл-манифест с версией формата, CRC32 и размером.
5. В режиме `verify` парсит манифест, вычисляет хеш указанной копии и сравнивает 
   его с эталонным, выводя детальную диагностику при несовпадении.
6. Использует `init.arena.allocator()` и `iterateAllocator` для безопасного и 
   идиоматичного управления памятью и аргументами командной строки.
