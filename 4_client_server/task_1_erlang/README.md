# Задача 4.1 — TCP-сервер управления таймерами (Erlang)

## Условие

Сервер на `gen_tcp` принимает подключения; на каждого клиента запускается 
отдельный процесс. Команды: `START имя секунды`, `STOP имя`, `LIST`, `QUIT`. 
Каждый таймер — отдельный процесс, который по истечении времени отправляет 
владельцу-клиенту сообщение `EXPIRED имя`. Имена таймеров уникальны в пределах 
клиента. `LIST` показывает активные таймеры и оставшееся время. При отключении 
клиента его таймеры останавливаются, неизвестные команды и повторное имя таймера 
дают текст ошибки.

## Что делает код

1. Запускает TCP-сервер на порту 4000 с опциями `{active, false}`, `{packet, line}`, 
   `{reuseaddr, true}`.
2. Принимает подключения через `gen_tcp:accept` и передает сокет дочернему процессу 
   через `gen_tcp:controlling_process`.
3. Обрабатывает команды клиента в цикле `client_loop` с flow control через 
   `{active, once}` — по одному сообщению за раз.
4. Создает таймеры через `spawn_link`, что связывает их с клиентским процессом 
   и гарантирует остановку при отключении клиента.
5. Хранит таймеры в мапе `%{Name => {Pid, Deadline}}%` и защищает от race condition 
   через проверку PID в сообщениях `expired`.
6. Парсит секунды через `try/catch` и отклоняет некорректный ввод.
