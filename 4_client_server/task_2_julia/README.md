# Задача 4.2 — TCP-калькулятор с переменными клиента (Julia)

## Условие

Каждый клиент обслуживается своей задачей (корутинной). Команды: `SET имя значение`, 
`EVAL выражение`, `VARS`, `QUIT`. Выражения содержат числа, переменные, операции 
`+ - * /` и скобки. Разборщик выражений пишется вручную, использовать встроенный 
`eval` запрещено. У каждого клиента своя таблица переменных. Сервер возвращает 
результат вычисления или текст ошибки (деление на ноль, неизвестная переменная, 
синтаксическая ошибка).

## Что делает код

1. Реализует лексер (`tokenize`), который разбивает строку на токены: числа 
   (включая научную запись), идентификаторы, операторы и скобки.
2. Реализует парсер методом рекурсивного спуска с правильным приоритетом операций: 
   `parse_expr` (сложение/вычитание), `parse_term` (умножение/деление), 
   `parse_factor` (унарные операторы), `parse_atom` (числа, переменные, скобки).
3. Проверяет деление на ноль, неизвестные переменные и синтаксические ошибки.
4. Обслуживает каждого клиента в отдельной корутине (`@async`), обеспечивая 
   изоляцию таблиц переменных.
5. Обрабатывает команды `SET`, `EVAL`, `VARS`, `QUIT` с детальной валидацией.
