# Задача 4.3 — TCP-сервер таблицы лидеров (Scala)

## Условие
Сервер хранит таблицу результатов (лидерборд) в общей структуре под блокировкой.
Команды: `SUBMIT игрок очки`, `TOP n`, `RANK игрок`, `RESET игрок`, `QUIT`.
Для каждого игрока учитывается лучший результат. При равенстве очков выше стоит тот, кто набрал их раньше. 
`TOP` возвращает `n` лучших с местами, `RANK` — место и очки игрока. 
Каждое подключение обрабатывается в отдельном потоке. При неверной команде, нечисловых очках или неизвестном игроке возвращается текст ошибки.

## Что делает код
1. Запускает `ServerSocket` на порту 5000 и принимает подключения в бесконечном цикле.
2. Для каждого клиента создается отдельный поток, что обеспечивает одновременную обработку множества подключений.
3. Использует потокобезопасную коллекцию (`synchronized` блок) для хранения данных лидерборда.
4. Команда `SUBMIT` обновляет результат игрока только если он строго лучше предыдущего (при равенстве сохраняется старая запись, так как она была получена раньше).
5. Команды `TOP` и `RANK` выполняют сортировку записей: сначала по убыванию очков, затем по возрастанию времени добавления.
6. Реализована надежная обработка ошибок: нечисловые очки, неизвестные игроки и неверные команды возвращают текстовое описание ошибки, не прерывая работу сервера.
