# Задача 4.4 — TCP-сервер для работы с полиномами (D)

## Условие
Сервер принимает TCP-подключения и обрабатывает команды для работы с полиномами:
`DEF имя коэффициенты`, `ADD a b`, `MUL a b`, `DIFF a`, `EVAL a x`, `SHOW a`, `QUIT`.
Каждое подключение обрабатывается в отдельном потоке. Коэффициенты хранятся как `long`,
все арифметические операции проверяются на целочисленное переполнение.
При ошибках ввода (нечисловые данные, неизвестный полином, деление на ноль) 
возвращается текстовое сообщение об ошибке. У каждого клиента своя таблица полиномов.

## Что делает код
1. Запускает `TcpSocket` на порту 6000 и принимает подключения в бесконечном цикле.
2. Для каждого клиента создается отдельный поток (`core.thread.Thread`), 
   обеспечивающий независимую обработку команд и изоляцию данных.
3. Функции `checkedAdd` и `checkedMultiply` гарантируют отсутствие тихого переполнения `long`, 
   выбрасывая исключение при выходе за границы.
4. Операции `addPolynomials`, `multiplyPolynomials` и `derivativePolynomial` 
   выполняют алгебраические действия, результат всегда нормализуется (удаляются старшие нули).
5. Функция `handleClient` корректно обрабатывает фрагментацию TCP-пакетов через 
   буферизацию строки `pending` и ограничивает длину команды константой `MAX_COMMAND_LENGTH`.
6. Блок `try-catch` в `processCommand` перехватывает ошибки парсинга и возвращает 
   клиенту понятное сообщение `ERROR`, не прерывая работу сервера.
