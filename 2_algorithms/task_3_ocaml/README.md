# Задача 2.3 — Максимальное паросочетание в двудольном графе (OCaml)

## Условие

Граф задаётся размерами долей (N и M) и списком рёбер «левая вершина — правая вершина». 
Паросочетание строится алгоритмом Куна: для каждой левой вершины ищется увеличивающая 
цепь поиском в глубину с массивом посещённых вершин. Структуры данных (списки смежности, 
массивы пар) реализуются самостоятельно. Программа выводит размер максимального 
паросочетания, сами пары и список вершин, оставшихся без пары, а также проверяет, 
что никакая вершина не используется дважды.

## Что делает код

1. Читает из `input.txt` размеры долей N и M, а также список рёбер. Выполняет строгую 
   проверку диапазонов вершин и корректности формата.
2. Строит список смежности для левых вершин на основе массива списков.
3. Реализует алгоритм Куна: рекурсивный поиск в глубину (`dfs`) ищет увеличивающую 
   цепь для каждой левой вершины, перенастраивая существующие пары при необходимости.
4. Выводит размер максимального паросочетания, список пар «левая -> правая», а также 
   списки несвязанных вершин для обеих долей.
5. Выполняет строгую проверку корректности: ни одна вершина не используется дважды, 
   и каждое ребро паросочетания реально существует в исходном графе.
