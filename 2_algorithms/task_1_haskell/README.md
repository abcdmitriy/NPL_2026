# Задача 2.1 — Рекурсивная генерация замощений доски (Haskell)

## Условие

Прямоугольная доска N×M (возможны заранее заданные запрещённые клетки) 
замащивается доминошками 1×2 без наложений и пропусков. 

Рекурсивная функция находит первую свободную клетку, пробует положить 
доминошку горизонтально и вертикально и продолжает на оставшейся части; 
результат — ленивый список всех замощений. 

Программа печатает общее число замощений и первое найденное в виде 
текстовой схемы, где каждая доминошка обозначена своей буквой. 
Если замощений нет (например, нечётное число свободных клеток), 
выводится соответствующее сообщение.

## Что делает код

1. Читает из `input.txt` размеры доски N и M, а также список координат 
   запрещённых клеток (попарно).
2. Создаёт двумерный массив `Array (Int, Int) Cell`, где каждая клетка — 
   `Empty`, `Blocked` или `Domino Char`.
3. Функция `findFirstEmpty` находит первую свободную клетку в порядке 
   обхода «построчно, слева направо».
4. Функция `generateTilings` рекурсивно пробует положить доминошку 
   горизонтально и вертикально, обновляя доску через оператор `//`, 
   и возвращает ленивый список всех замощений.
5. Перед запуском поиска проверяется чётность числа свободных клеток: 
   если оно нечётное, замощений заведомо нет.
6. Выводится общее число замощений и первое найденное в виде сетки, 
   где каждая доминошка обозначена уникальной буквой (A, B, C, ...).
