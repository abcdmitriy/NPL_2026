# Задача 2.2 — Решение нонограммы перебором с возвратом (Prolog)

## Условие

Прямоугольная доска N×M должна быть заполнена закрашенными и пустыми клетками 
так, чтобы длины последовательных блоков закрашенных клеток в каждой строке 
и столбце соответствовали заданным числовым подсказкам. 

Программа находит все возможные решения с использованием перебора с возвратом 
и отсечением ветвей, выводит их количество и показывает первое решение в виде 
текстовой сетки (где `#` — закрашенная клетка, `.` — пустая). 
Если подсказки противоречивы, выводится сообщение об отсутствии решений.

## Что делает код

1. Читает из `input.txt` размеры доски N и M, а также списки подсказок 
   для строк и столбцов.
2. Использует DCG (Definite Clause Grammar) для декларативного описания 
   шаблонов строк и столбцов (`block_pattern`, `zeros`, `ones`).
3. Построение сетки идет построчно (`solve_rows`). После добавления каждой 
   строки проверяется частичная совместимость столбцов 
   (`partial_columns_compatible`). Это позволяет отсекать заведомо тупиковые 
   ветви перебора на ранних этапах.
4. Предикат `findall` собирает все найденные решения. Выводится их количество 
   и первое решение в виде текстовой сетки.
5. Программа корректно обрабатывает противоречивые входные данные, сообщая, 
   что решений не найдено.
