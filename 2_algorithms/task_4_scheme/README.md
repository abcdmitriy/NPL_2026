# Задача 2.4 — Рекурсивное вычисление расстояния между деревьями (Scheme)

## Условие

Два упорядоченных помеченных дерева задаются S-выражениями вида `(a (b) (c (d)))`. 
Рекурсивно вычисляется расстояние редактирования деревьев — минимальное число операций 
вставки узла, удаления узла и замены метки, превращающих одно дерево в другое. 
Рекурсия идёт по лесам (списку поддеревьев), промежуточные результаты запоминаются 
в таблице (мемоизация). Программа печатает расстояние и одну из минимальных 
последовательностей операций. Сообщается об ошибке при неверном S-выражении 
(незакрытая скобка, пустой ввод).

## Что делает код

1. Читает из `input.txt` два S-выражения с использованием `call-with-input-file` 
   и проверяет их корректность через рекурсивный предикат `valid-tree?`.
2. Использует структуру `dp-result` для хранения не только минимального расстояния, 
   но и принятого решения (`choice`), а также хеш-таблицу для эффективной мемоизации.
3. Рекурсивно вычисляет расстояние между лесами, рассматривая три варианта: 
   сопоставление корней (с возможной заменой метки), удаление узла и вставка узла.
4. Восстанавливает и выводит одну из минимальных последовательностей операций 
   с подробным контекстом (например, «дочерний лес узла 'b'»).
5. Выполняет проверку корректности (sanity check): сравнивает вычисленное расстояние 
   с фактическим количеством восстановленных операций.
