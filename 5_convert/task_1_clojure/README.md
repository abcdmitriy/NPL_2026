# Задача 5.1 — Конвертер TOML в JSON (Clojure)

## Условие
Программа читает файл в формате TOML, парсит его содержимое (включая комментарии, 
массивы, вложенные таблицы, строки, булевы значения и числа) и преобразует 
результат в форматированный JSON. Используется строгая валидация синтаксиса 
с указанием номера строки при ошибке.

## Что делает код
1. Реализует лексический и синтаксический анализ TOML без внешних библиотек.
2. Корректно обрабатывает строки с escape-последовательностями и игнорирует 
   символы `#` и `=` внутри кавычек.
3. Использует `BigInteger` и `BigDecimal` для точного представления чисел, 
   и `LinkedHashMap` для сохранения порядка ключей при выводе JSON.
4. Рекурсивно генерирует JSON с правильными отступами (`indentation`) и 
   экранированием спецсимволов (`escape-json`).
5. Поддерживает вывод как в консоль, так и в указанный файл `output.json`.
