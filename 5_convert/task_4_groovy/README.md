# Задача 5.4 — Конвертер BMP в PPM (Groovy)

## Условие
Программа читает растровое изображение в формате BMP (24-битное, без сжатия), 
парсит его бинарный заголовок и данные пикселей, и конвертирует их в текстово-бинарный 
формат PPM (P6).

## Что делает код
1. Реализует побайтовое чтение Little Endian значений (`readU8`, `readU16`, `readU32`) 
   с корректной обработкой знакового типа `byte` в JVM через `& 0xFF`.
2. Строго валидирует заголовок BMP: сигнатуру "BM", 1 цветовую плоскость, 
   24 бита на пиксель и отсутствие сжатия.
3. Корректно вычисляет 4-байтовое выравнивание (padding) каждой строки пикселей 
   с помощью формулы `Math.floorDiv(rowSize + 3, 4) * 4`.
4. Поддерживает как стандартный порядок строк (снизу вверх, отрицательная высота), 
   так и прямой порядок (сверху вниз).
5. Выполняет побайтовую конвертацию цветового пространства из BGR (формат BMP) в RGB (формат PPM).
6. Записывает результат в формате PPM P6 с ASCII-заголовком.
