# Задача 5.2 — Конвертер BIB в JSON (F#)

## Условие
Программа читает файл в формате BibTeX (BIB), парсит библиографические записи 
(тип записи, ключ цитирования, поля) и преобразует результат в форматированный JSON-массив.
Поддерживается раскрытие макросов (@string), игнорирование @comment и @preamble, 
а также специальное форматирование поля author (разделение по " and " в массив).

## Что делает код
1. Реализует парсер рекурсивного спуска на F# без использования сторонних библиотек.
2. Методы `ReadBracedValue` и `ReadQuotedValue` корректно обрабатывают вложенные 
   фигурные скобки и экранированные кавычки.
3. `ParseValueExpression` поддерживает конкатенацию строк через символ `#`.
4. `ParseStringEntry` раскрывает встроенные макросы месяцев и пользовательские макросы.
5. `AddField` специально обрабатывает поле `author`, разбивая его регулярным выражением 
   на JSON-массив отдельных авторов.
6. Используются `JsonSerializerOptions` с `UnsafeRelaxedJsonEscaping` для сохранения 
   фигурных скобок в названиях и `UTF8Encoding(false)` для записи без BOM.
7. Выдает понятные ошибки с указанием номера строки при синтаксических нарушениях.
