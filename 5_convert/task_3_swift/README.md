# Задача 5.3 — Конвертер RSS (XML) в Markdown (Swift)

## Условие
Программа читает файл в формате RSS (XML), парсит его содержимое (заголовок канала, 
описание, список записей с заголовком, ссылкой, датой и описанием) и преобразует 
результат в форматированный Markdown-документ.

## Что делает код
1. Использует событийный `XMLParser` (SAX) с кастомным делегатом `RSSParserDelegate`, 
   отслеживающим глубину вложенности (`elementStack`) для корректного извлечения 
   полей внутри `<channel>` и `<item>`.
2. Поддерживает чтение как обычного текста (`foundCharacters`), так и CDATA-блоков.
3. Функция `removeHTML` в два этапа преобразует структурные теги (`<br>`, `</p>`) 
   в переносы строк, а затем удаляет все остальные теги, комментарии и скрипты.
4. Функция `decodeHTMLEntities` декодирует именованные, десятичные и шестнадцатеричные 
   HTML-сущности с безопасной заменой в обратном порядке.
5. Функция `escapeMarkdown` экранирует все символы пунктуации обратным слешем, 
   предотвращая случайное срабатывание синтаксиса Markdown.
6. Отключает разрешение внешних сущностей (`shouldResolveExternalEntities = false`) 
   для защиты от XXE-уязвимостей.
