# Задача 1.4 — Параллельный поиск групп анаграмм по словарю (Elixir)

## Условие

Файл-словарь (по одному слову в строке) делится на куски. Каждый кусок 
обрабатывает отдельный процесс-воркер: слова группируются по ключу из 
отсортированных букв (например, для "listen" и "silent" ключ будет "eilnst"). 

Процесс-коллектор получает сообщения от воркеров и сливает группы анаграмм. 
Программа печатает число групп размера не меньше 2 и пять самых больших групп.

## Что делает код

1. Читает текст из `input.txt` (или генерирует 100 000 случайных слов, если файл не найден).
2. Функция `find_sequential` выполняет последовательный поиск: группирует слова 
   по отсортированным буквам и оставляет только группы размером >= 2.
3. Функция `find_parallel` запускает процессы-воркеры через `spawn_monitor`. 
   Каждый воркер обрабатывает свой кусок словаря и отправляет частичные группы 
   процессу-коллектору через `send`.
4. Процесс-коллектор (`collector_loop`) принимает сообщения, сливает карты 
   анаграмм и по завершении всех воркеров отправляет финальный результат 
   главному процессу.
5. Замер времени выполняется для последовательного и параллельного алгоритмов, 
   результаты сравниваются после нормализации.
