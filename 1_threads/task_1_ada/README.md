# Задача 1.1 — Параллельное вычисление сумм строк и столбцов матрицы (Ada)

## Условие

Матрица целых чисел читается из текстового файла (первая строка — размеры `N M`).
Строки делятся на горизонтальные полосы, каждая полоса обрабатывается отдельной
Ada-задачей (`task`): считаются суммы строк и частичные суммы столбцов. Частичные
результаты передаются в защищённый объект (`protected object`), где объединяются.
В конце проверяется, что сумма сумм строк равна сумме сумм столбцов, печатается
максимальная сумма строки и время работы для 1 и N задач.

## Что делает код

1. Читает `N`, `M` и элементы матрицы из `input.txt` (или из файла, переданного
   аргументом командной строки).
2. Делит строки на горизонтальные полосы и создаёт по одной задаче `Worker` на
   каждую полосу (границы `First_Row .. Last_Row` передаются через дискриминанты).
3. Каждая задача одним проходом по своей полосе считает суммы строк и накопляет
   локальные частичные суммы столбцов.
4. Результаты передаются в защищённый объект `Result_Store`: `Add_Row` — сумма
   строки и обновление максимума, `Add_Columns` — добавление частичных сумм
   столбцов, `Worker_Done` — отметка о завершении задачи.
5. Главная программа ждёт все задачи на входе `Wait_Complete` с барьером
   `Finished = Workers`.
6. Печатает суммы всех строк и столбцов, максимальную сумму строки и её номер,
   общие суммы и результат проверки `Σ строк = Σ столбцов`.
7. Прогон выполняется дважды — `Run(1)` и `Run(N)`, для каждого замеряется и
   выводится время работы (`Ada.Real_Time`).

Суммы хранятся в `Long_Long_Integer`, поэтому переполнения при больших матрицах нет.
