# Задача 1.3 — Параллельный поиск палиндромных подстрок фиксированной длины (Rust)

## Условие

Программа читает текст из файла (или генерирует случайную строку над алфавитом
{a, b, c, d}) и ищет все позиции, где начинается подстрока-палиндром заданной
длины `L`.

Строка делится на фрагменты между потоками (`std::thread`) с перекрытием в
`L−1` символов, чтобы не потерять палиндромы на границах фрагментов. Каждый
поток проверяет все подстроки длины `L` в своём фрагменте и отправляет
найденные позиции через канал `mpsc` в главный поток. Главный поток объединяет
результаты без дубликатов (через `HashSet`).

Программа печатает общее число палиндромов, первые десять позиций с подстроками
и самую частую палиндромную подстроку. Результат сравнивается с
последовательным поиском, выводится время обоих вариантов для разного числа
потоков.

## Что делает код

1. Читает текст из `input.txt` (или генерирует 1 000 000 символов, если файл не
   найден).
2. Функция `is_palindrome` проверяет срез символов на палиндромность.
3. Функция `find_sequential` выполняет последовательный поиск всех позиций
   палиндромов длины `L`.
4. Функция `find_parallel` распределяет позиции между потоками равномерно,
   каждый поток проверяет свой фрагмент с перекрытием `L-1` и отправляет
   результаты через `mpsc::channel`. Главный поток собирает их в `HashSet` для
   устранения дубликатов.
5. Функция `most_frequent` находит самую частую палиндромную подстроку среди
   найденных.
6. Замер времени выполняется для 1, 2, 4 и 8 потоков, результаты сравниваются
   с последовательным поиском.
